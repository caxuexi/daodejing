# 道德经 · 八十一章（原文 + 韩鹏杰极简白话译文）

《道德经》全文八十一章，配韩鹏杰极简白话译文，以单文件网页形式呈现，可直接部署到 GitHub Pages 等静态托管平台在线阅读。

在线预览：`https://<用户名>.github.io/<仓库名>/`（部署后替换为实际地址）

## 简介

- **数据来源**：《道德经》81章原文及韩鹏杰极简白话译文.pptx
- **内容范围**：封面、目录、道经（第一章 — 第三十七章）、德经（第三十八章 — 第八十一章）、结尾，共 81 章逐章对照
- **形式**：一个完全自包含的 `index.html`，所有图片内嵌为 base64，无任何外部依赖

## 功能

- 左侧固定**章节目录**：按「道经 / 德经」分组，滚动时自动高亮当前章节
- **关键字搜索**：输入即时筛选目录并统计命中章节数；正文命中处高亮、非命中章节淡出；`Enter` 跳转首个结果，`Esc` / × 清空
- **响应式布局**：移动端目录抽屉式收起，桌面端双栏阅读
- 每章包含：原文、白话译文，并保留原幻灯片中的章首引句、章旨悟读与插画

## 风格

还原原 PPT 的宣纸质感与配色：宣纸纹理底、棕红主色 `#8C4B3D`、深棕正文 `#332620`、楷体字体，以及封面「老子骑牛」水墨图与竹简结尾页。

## 本地预览

直接用浏览器打开 `index.html` 即可；也可在目录内启动一个本地服务器：

```powershell
python -m http.server 8000
# 或（已安装 Node.js）
npx serve
```

然后访问 `http://localhost:8000/`。

## 部署到 GitHub Pages

1. 新建仓库并推送本目录内容（入口文件命名为 `index.html`）。
2. 打开仓库 **Settings → Pages**，Source 选择 `Deploy from a branch`，Branch 选 `main`、目录选 `/ (root)`，保存。
3. 稍等 1–2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

> 若仓库名为 `<用户名>.github.io`，则访问地址为 `https://<用户名>.github.io/`。
